# CV_project
An AI-powered computer vision system designed to help visually impaired passengers identify buses at bus stops. Using YOLO-based bus detection, OCR-based bus number recognition, and text-to-speech technology, the system aims to automatically detect approaching buses, identify bus numbers, announce route information through voice output, and maintain recently departed bus history. The project uses Python, OpenCV, YOLO, Tesseract OCR, and text-to-speech technologies to improve public transportation accessibility.
## Technologies Used
- Python
- OpenCV
- YOLO
- Tesseract OCR
- Pyttsx3
